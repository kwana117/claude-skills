03 · Workshops · Spec fechada

Inscrição, pagamento, certificado, feedback.

Tudo automatizado. Fluxo completo do participante, do backoffice e das integrações.

Fluxo do participante
📝 Inscrição → ☑️ Quer certificado? (+10€) → 💳 Payments API (se sim) → 🧾 Fatura Billing API → 📧 Confirmação + ICS → 📅 Calendar → 🎓 Workshop + feedback → 🏅 Certificado

📝 Inscrição

  • Nome, último nome, email
  • Checkbox "Quero certificado (+10€)"
  • NIF opcional · senão "consumidor final"
  • Se checkbox → pagamento Payments API antes de confirmar
  • Se não → confirmação directa

📧 Emails

  • Confirmação com .ics (Google / Outlook)
  • Lembrete 1 semana antes
  • Lembrete na véspera (com link do workshop)
  • Feedback logo após o workshop
  • Envio via Resend

🗂️ Backoffice

  • Área Participantes
  • Área Eventos: nome, data, hora, formador, link
  • Tabela Oradores (apresentação breve)
  • Gestor marca "assistiu sim/não" → dispara feedback
  • Gestor emite certificado no dia seguinte

⚖️ Política + FAQ

  • Cancelamento até 48h antes → reembolso total
  • Após 48h → só com justificação (tipo falta laboral)
  • FAQ no rodapé: requisitos técnicos, cancelamento, certificado
